WHAT IS IN THE BUILD
This is a no-build vanilla JavaScript frontend, Python standard-library HTTP/API server, and local SQLite casebook. It contains five independent synthetic operational applications:
1. Infrastructure Health Monitor — investigate an alert, record hypothesis/action, and verify recovery.
2. Security Findings Dashboard — assign ownership, triage risk, plan response, and resolve with evidence.
3. IT Helpdesk Ticket System — create and progress requests with ownership, first-response targets, notes, and resolution evidence.
4. Network Fault Isolation Tool — run rule-based checks across impact scope and fault domains, then hand off diagnostic evidence.
5. Maintenance Approval & Rollback — satisfy readiness and peer-review gates, confirm the window, validate implementation, and document rollback.

The backend persists casebook state in SQLite, uses expected-revision checks for concurrent updates, retains up to 25 snapshots, and provides history/restore endpoints plus an integrity-checked backup utility. Existing browser-local state can be migrated on first startup. Details and limits are documented in README.md.
